# About Diplodoc

Diplodoc is a platform for working with documentation based on the "docs as code" approach.

## Use cases

| Server version | Static documentation |
|-----------------|-------------------------|
| **Option with hosting on the service side:** | **Option of using via the command-line interface (CLI):** |
| - Processing and rendering of content on Diplodoc resources. | - Generation of static HTML pages via CLI. |
| - Integration with GitHub for working with Markdown files: automatic generation of documentation on the [diplodoc.com](https://diplodoc.com/) domain. | - Deployment on any hosting platforms. |
| - Support for proxying from custom domains. | - Integration with CI/CD pipelines. |
